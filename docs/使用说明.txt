桌面文字 · 使用说明

启动
双击「桌面文字.app」。应用运行后，屏幕顶部菜单栏会出现「桌面文字」。
应用无需上架或联网；当前下载版本使用本机构建签名。

第一次使用
1. 首次启动会显示示例文字。若已经锁定，点击右上方「解锁并编辑」。
2. 在「文字内容」中输入提醒或日程，选择字体、字号、颜色和其他样式。
3. 收起编辑窗口，切回桌面。拖动文字上方的小条定位，拖动右下角调整文字框大小。
4. 点击桌面文字上方的小锁，或在桌面编辑时按 Esc。也可以在管理窗口点击「锁定这段文字」。
5. 锁定后不能在桌面拖动、选中文字或编辑；点击会穿过文字，操作下方的桌面或应用。

再次修改
点击屏幕顶部菜单栏「桌面文字」→「管理与编辑…」→「解锁并编辑」。
也可以从菜单栏中找到对应的一段文字，选择「解锁并编辑」。

显示方式
贴在桌面：文字位于桌面上，普通应用窗口可以盖住它。
始终置顶：锁定后，文字显示在普通应用窗口上方，鼠标仍然穿透。
字体、字号、样式和显示方式在解锁状态下调整。

新增、删除和退出
「＋ 新增文字」可创建多段独立文字。
删除的文字可以从菜单栏选择「恢复最近删除的文字」。
关闭或收起编辑窗口后，应用仍在菜单栏运行。
完全退出：菜单栏「桌面文字」→「退出桌面文字」。
登录时自动启动为可选设置，默认不启用。

保存
文字、样式、位置、显示方式和锁定状态均自动保存在本机。
移动或替换应用文件不会删除已经保存的文字。
数据位置：个人资源库 / Application Support / DesktopText / notes.json

运行环境
要求 macOS 14 或更高版本，下载版本适用于 Apple 芯片 Mac。
Intel Mac 可以从源码构建对应架构的版本。
下载版本尚未经过 Apple Developer ID 签名和公证，其他 Mac 从网络下载后可能被系统拦截；可在自己的 Mac 上从源码构建。
